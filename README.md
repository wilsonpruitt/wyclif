# Wyclif — the Latin works in English

Wroot Press. The whole Wyclif Society corpus (33 volumes, 1883–1922, ~2.6M Latin words) in English,
queued toward the untranslated church and polemical works first. Will live at
**wyclif.wrootpress.com**.

- **`PLAN.md`: the plan of record. Read first.**
- `CONVENTIONS.md` + `GLOSSARY.md`: the rules every chunk follows (pilot draft until Wilson approves).
- `LEDGER.md`: status of every source identification; nothing `to-verify` ships.
- `pilots/`: the two pilot chunks (De ecclesia I A–C, plate-read; Dialogus 1, Fordham-collated).
- `PHASE0.md`: what is on disk, the witness and data findings. `catalog/volumes.tsv`: the queue.
- `scripts/plate.sh SLUG PAGE`: fetch a Society page image (calibrated volumes only).

Latin: public domain. English translation and encoding: CC BY-NC 4.0.
