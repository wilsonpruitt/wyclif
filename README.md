# Wyclif — the Latin works in English

Wroot Press. The whole Wyclif Society corpus (33 volumes, 1883–1922, ~2.6M Latin words) in English,
queued toward the untranslated church and polemical works first. Will live at
**wyclif.wrootpress.com**.

- `PHASE0.md`: what is on disk, the witness and data findings, the queue. **Read first.**
- `catalog/volumes.tsv`: one row per volume, in queue order.
- `PLAN.md` / `CONVENTIONS.md`: not yet written (Fable session).
