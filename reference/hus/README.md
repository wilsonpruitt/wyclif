# Hus companion — parked until Wyclif is finished

**Status: not started. Do no work here until the Wyclif corpus is done** (Wilson, 2026-10-04).

`hus_text_locator.csv` lists 48 sources for Jan Hus (Latin, Czech, letters, documents,
old prints, Czech cribs, reference catalogues): where each text is, its OCR quality, rights,
and whether it can serve as a base text (`base_text` column). Items marked CHECK are unverified.

## Two connections

1. **Wyclif (this repo).** Hus is the reception layer of Wyclif — see "Hus parallels" under
   *Deferred layers* in `PLAN.md`. Loserth, *Hus und Wiclif* (1884; row 39 in the CSV) maps
   where Hus's text is Wyclif's verbatim; it is the spine for passage-by-passage parallels.
2. **The Sentences work (`~/wroot-press/sentences`).** Hus's *Super IV Sententiarum*
   (1407–09; rows 2–5) is a commentary on Lombard, untranslated. Its home address is
   the Lombard daf, keyed by book and distinction.
